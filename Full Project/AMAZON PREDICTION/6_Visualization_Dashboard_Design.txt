VISUALIZATION DASHBOARD SPECIFICATIONS
Project: Amazon Sales Analysis & Prediction Application

The visualization module complements the Machine Learning backend by providing interactive insights via Tableau. The system features three distinct dashboard types tailored for different analytical needs, integrated directly with the cleaned CSV datasets.

DASHBOARD 1: EXECUTIVE SALES OVERVIEW (Strategic)
Purpose: Provides high-level visibility into total revenue, ratings, and regional performance for business owners.
• Data Source: amazon_sales_cleaned.csv (Dress Data)
• Key Components:
  1. KPI Cards: Total Revenue (Sum of Amount), Average User Rating, Total Orders.
  2. Geographic Heatmap: Visualizes sales volume by 'Ship-State' (Darker shade = Higher Revenue).
  3. Regional Filter: Dropdown to toggle between North, South, East, and West regions.
• Insight: Identifies the top-performing states (e.g., Maharashtra, Karnataka) to optimize logistics.

DASHBOARD 2: PREDICTIVE TREND ANALYSIS (Operational)
Purpose: Visualizes historical sales against Random Forest model forecasts to track seasonality and growth.
• Data Source: electronics_cleaned.csv (Electronics Data)
• Key Components:
  1. Time-Series Trend Line: Line chart showing Monthly Sales (Y-axis) vs. Time (X-axis).
  2. Forecast Overlay: Dotted line representing the "Predicted Sales" generated by the Random Forest model.
  3. Category Filter: Multi-select option for specific categories (Mobiles, Computers, Accessories).
• Insight: Highlights seasonal spikes (e.g., Q4 Festive/Holiday Sales) to aid in marketing timing.

DASHBOARD 3: INVENTORY & CATEGORY PERFORMANCE (Tactical)
Purpose: Granular product-level details to assist inventory managers in stocking decisions.
• Data Source: grocery_sales_data_cleaned.csv (Grocery Data) / amazon_sales_cleaned.csv
• Key Components:
  1. Category Market Share (Donut Chart): Percentage breakdown of sales by Category (Kurta, Saree, Top).
  2. Top 10 Bestsellers: Sorted table listing specific items by 'Sales Quantity'.
  3. Price vs. Volume Scatter Plot: Correlates 'Quantity' sold with 'Price' to find optimal pricing sweet spots.
• Insight: Determines which products are "Stars" (High Volume, High Revenue) vs. "Slow Movers".

TECHNICAL IMPLEMENTATION
• Connection: Live Text File connection to project 'data/' folder.
• Interactivity: Global 'Year' filter links all three dashboards.
• Integration: Dashboards to be embedded in the Flask web app via IFrame or linked in the navigation menu.
